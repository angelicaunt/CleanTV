## 💜 What is CleanTV?

**CleanTV** is a Windows utility designed to make Android TV maintenance simple and automated.

It identifies your connected television, detects its Android version, finds and downloads suitable unofficial firmware, and automates the supported firmware and cleanup workflow.

No more manually searching for device information, hunting for firmware packages, or dealing with unnecessary preinstalled applications.

<div align="center">

| 🔍 Automatic Detection | 📦 Firmware Selection | 🧹 System Cleanup |
|:---:|:---:|:---:|
| Identify your TV | Find suitable firmware | Remove unwanted software |
| ⚡ Automated workflow | 📺 Device-specific | 🚀 Smoother experience |

</div>

## ✨ Features

### 🔍 Automatic Device Detection

CleanTV automatically identifies the connected Android TV and retrieves available system information.

- Detects the device model.
- Identifies the Android version and available build information.
- Uses device information to determine suitable firmware options.
- Simplifies the initial setup process.

### 📦 Smart Firmware Selection

Finding the right unofficial firmware can be complicated. CleanTV automates the process for supported devices.

- Searches for suitable firmware for the detected device.
- Selects an appropriate candidate using available compatibility information.
- Downloads the selected firmware package.
- Streamlines the firmware installation workflow.

> 💡 Firmware compatibility depends on the exact model, hardware revision, region, and available firmware sources.

### ⚙️ Automated Firmware Workflow

Manage the supported firmware process through a unified Windows application.

- Reduce repetitive manual steps.
- Automate supported firmware operations.
- Track operation progress and diagnostic logs.
- Simplify device maintenance with a guided workflow.

### 🧹 Bloatware Removal

Get rid of unnecessary software that can make Android TV frustrating to use.

- Remove or disable unwanted preinstalled applications where supported.
- Target advertising-related software and unnecessary components.
- Help reduce avoidable background activity.
- Create a cleaner software environment for everyday use.

The available cleanup operations depend on the device and firmware. Essential system components must be handled carefully to avoid breaking core functionality.

### 🚀 Performance Optimization

A cleaner system can mean fewer unnecessary applications and less background activity.

CleanTV is designed to help improve responsiveness by reducing unwanted software overhead on supported devices.

## 📺 Compatibility

CleanTV is intended for supported Android TV devices.

Compatibility may depend on:

- 🏷️ Manufacturer and exact model.
- 🔧 Hardware revision and system board.
- 🤖 Android version and firmware build.
- 🔒 Bootloader and recovery capabilities.
- 📦 Availability of compatible unofficial firmware.

Not every television can use the same firmware image. Installing firmware intended for another device can prevent the TV from booting.

Check the project's compatibility information and release notes before proceeding.

---

## 🛡️ Safety First

Firmware modification carries risks, including data loss, boot failure, and permanent device damage.

Before starting:

- ✅ Confirm that the firmware matches the exact device and hardware variant.
- ✅ Keep the TV connected to reliable power during critical operations.
- ✅ Back up important information where possible.
- ✅ Understand the available recovery method before flashing.
- ✅ Review cleanup candidates and their purpose.
- ✅ Avoid removing essential system components without device-specific verification.

**Never install a firmware image simply because it supports the same Android version.**

Use CleanTV only on devices you own or are authorized to maintain.

## ❓ FAQ

<details>
<summary><strong>📺 Does CleanTV support every Android TV?</strong></summary>

No. Firmware compatibility varies by device and hardware revision. Use firmware intended for the exact supported model.

</details>

<details>
<summary><strong>🧹 Does CleanTV remove all advertising?</strong></summary>

CleanTV targets unwanted preinstalled applications and advertising-related software where supported. Some advertising features may be integrated into essential system components and cannot safely be removed independently.

</details>

<details>
<summary><strong>⚡ Will my TV become faster?</strong></summary>

Reducing unnecessary software and background activity can improve responsiveness on some devices. The project's reported 2× improvement refers to its internal testing and should not be treated as a guarantee for every TV.

</details>

<details>
<summary><strong>⚠️ Can unofficial firmware damage my TV?</strong></summary>
