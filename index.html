Know your device

Compatibility matters.

Android TV devices differ in hardware, bootloader configuration, system partitions, and firmware availability. Firmware selection must be specific to the intended device.

📺 Device Compatibility

Compatibility can depend on the manufacturer, exact model, hardware revision, Android build, bootloader, and available recovery method.

  • Check the exact device model
  • Verify the intended firmware variant
  • Review the release instructions
  • Understand recovery options before flashing

🛡️ A Note on Safety

Firmware modification can cause data loss or prevent a device from booting. Do not install an image just because it supports the same Android version.

  • Back up important information where possible
  • Maintain reliable power during critical operations
  • Avoid removing essential system components
  • Use only devices you own or may administer
Performance & responsiveness

Less unnecessary software.
More control.

CleanTV aims to reduce unwanted software overhead and background activity on supported televisions. According to the project's internal tests, certain devices achieved at least a 2× improvement in the measured performance metric under the tested conditions.

Results vary by hardware, original firmware, workload, and measurement method. The reported result is not a universal guarantee for every television.

Frequently asked questions

Good to know.

Does CleanTV support every Android TV?

Compatibility depends on the exact model, hardware revision, Android build, and available firmware. Check the project's release documentation before using firmware operations.

Can CleanTV remove all advertising?

CleanTV targets unwanted preinstalled and advertising-related software where supported. Some features are integrated into essential system components and may not be safely removable.

Will my television become faster?

Reducing unnecessary software can improve responsiveness on some devices. Results depend on the original system and the performance metric being measured.

Is unofficial firmware safe?

It can carry significant risks if the image is incompatible or the process is interrupted. Verify the exact device match and understand the recovery procedure before proceeding.

Where can I download CleanTV?

The latest available Windows release is published on the project's official GitHub Releases page.
